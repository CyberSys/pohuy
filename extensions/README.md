# Расширение для Pi

Расширение [`pohuy.ts`](./pohuy.ts) добавляет команду `/pohuy` и интерактивные настройки источников стиля.

## Установка

```bash
pi install git:github.com/smixs/pohuy
```

После установки или обновления выполните `/reload`.

## Команды и переключение режима

`/pohuy` открывает настройки в TUI. Быстрые команды переключают калибр без открытия интерфейса:

```text
/pohuy lite
/pohuy full
/pohuy ultra
/pohuy normal
```

`normal` выключает стиль ответов и удаляет управляемый блок Pohuy из системного промпта.

Те же переключатели работают отдельными фразами:

- «та мне похуй» и «заебал» включают `full`;
- «нормальный режим» и «хватит материться» выключают стиль.

Распознанная фраза работает как управляющая команда и не отправляется модели как пользовательский запрос.

## Настройки

### Mode

Выбирает `normal`, `lite`, `full` или `ultra`.

### Source preset

- `tier-defaults` использует стандартный набор секций выбранного уровня;
- `custom` сохраняет пользовательский набор секций.

Разделы `Skill`, `Dictionary` и `Scenes` позволяют независимо включать найденные секции из [`SKILL.md`](../skills/pohuy/SKILL.md), [`slovar.md`](../skills/pohuy/references/slovar.md) и [`sceny.md`](../skills/pohuy/references/sceny.md). Невыбранные дополнительные секции в системный промпт не попадают.

Выбранные источники компилируются без потери авторского материала:

- если вместе с рабочим минимумом выбрана полная словарная категория, краткий вариант этой категории из минимума не дублируется;
- в сценах с вариантами `lite`, `full` и `ultra` остаётся только пример активного уровня;
- остальные примеры и выбранные сцены сохраняются полностью, без символьной обрезки, token cap или скрытого лимита количества.

## Хранение настроек

Выбор сохраняется глобально в `~/.pi/agent/settings.json` и действует после перезапуска Pi и в других проектах. Расширение изменяет только ключ `pohuy`:

```json
{
  "pohuy": {
    "tier": "ultra"
  }
}
```

Если `settings.json` содержит повреждённый JSON, расширение запускается с безопасными значениями по умолчанию. При следующем изменении настроек исходный файл сохраняется рядом как `settings.json.corrupt-*`, после чего записывается новый валидный файл.

Отсутствующий `selectedSections` использует defaults активного tier. Явный пустой массив отключает все дополнительные секции:

```json
{
  "pohuy": {
    "tier": "full",
    "selectedSections": []
  }
}
```

## Композиция системного промпта

Расширение сохраняет уже собранный системный промпт Pi и помещает управляемый блок стиля непосредственно перед пользовательским `appendSystemPrompt`, когда такой сегмент присутствует. Оно не пересобирает базовый промпт, поэтому внутренние и сторонние context lanes остаются в исходном порядке.

Управляемый блок ограничен маркерами:

```text
<!-- POHUY:START -->
...
<!-- POHUY:END -->
```

Перед вставкой расширение удаляет все завершённые блоки между собственными маркерами и добавляет один текущий экземпляр. Это делает обработчик идемпотентным при повторных вызовах и не затрагивает текст без полного парного диапазона маркеров.

Расширение не дедуплицирует произвольные project context или session lanes. Оно устраняет только известные семантические пересечения собственных источников. Если одинаковый внешний контекст приходит из нескольких владельцев, его нормализация и provenance относятся к сборщику промпта Pi, а не к этому пакету.

## Ограничения стиля

Стиль применяется только к естественному тексту ответов. Tool calls, structured output, код, команды, идентификаторы, строки ошибок, коммиты, PR и документация сохраняют требуемый формат. Для security-предупреждений и подтверждения необратимых операций действует режим без юмора.

## Быстрая проверка

```text
> /pohuy ultra
Pohuy enabled: ultra.

> объясни, почему тест флакает
# ответ остаётся технически точным, но использует выбранный стиль

> /pohuy normal
Pohuy disabled. Normal mode restored.
```

В RPC и других режимах без TUI команда `/pohuy` без аргумента выводит предупреждение; быстрые команды с аргументом продолжают работать.
